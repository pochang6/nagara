# nagara

Mac で AI エージェントのコメントを、自分好みの音声で聴きコントロールするための Player アプリ。

Claude Code の返してくる長い応答を、**読むのではなく聴く**ためのものです。
ながら聞きの「ながら」から名前を取りました。

```
nagara は画面を読みません。投げ込まれたテキストだけを読みます。
```

---

## これは何で、何ではないか

Claude Code の読み上げは長くなると早口になり、声も選べません。かといって
既存の読み上げツールはどれも「応答が終わったら鳴らす」だけで、**止める・戻す・速度を変える**が
ありません。長文を流し聞きするには、通知ではなく**プレイヤー**が要ります。

**やること**

- 好きな音声モデルで読む（AivisSpeech / VOICEVOX のモデルなら何でも）
- 再生・一時停止・停止・**1文戻る**・速度変更（1.0 / 1.2 / 1.5）
- 届いた応答を溜めておき、**聴きたくなったときに再生する**
- 選択したテキストを右クリックから読む

**やらないこと**

- 画面のスキャン、OCR、アクセシビリティツリーの巡回。**スクリーンリーダーではありません**
- 音声認識・対話。喋りかける側は [nobetsu](https://github.com/pochang6/nobetsu) の担当です
- 音声合成そのもの。AivisSpeech に HTTP で頼むだけで、同梱もリンクもしません

メニューバーが勝手に読み上げられることはありません。読むのは**明示的に渡されたテキストだけ**です。

---

## 必要なもの

- macOS 26 以降
- [AivisSpeech](https://aivis-project.com/)（または [VOICEVOX](https://voicevox.hiroshiba.jp/)）
  - 起動していなければ nagara が裏で起こします。常駐させておく必要はありません
  - VOICEVOX を使う場合は、設定の `engineURL` を `http://127.0.0.1:50021` に変えてください

macOS の許可（入力監視・アクセシビリティ）は**一切要りません**。

---

## 入れる

```bash
./build.sh          # ビルドして /Applications へ設置し、CLI も置く
open /Applications/nagara.app
./install-claude.sh # Claude Code 側に Stop フックと /speak /stop を設置
```

`build.sh` はコード署名の証明書を探します。無ければ作り方を案内します（1回だけの作業です）。
`install-claude.sh` の登録先は `~/.claude/settings.json` なので、**ターミナル版でもデスクトップ版でも同じように効きます**。

外すとき:

```bash
./install-claude.sh --uninstall
```

## 使う

### ショートカット

| 操作 | キー |
|---|---|
| 再生 / 一時停止 | `⌃⌥P` |
| 速く（1段） | `⌃⌥→` |
| 遅く（1段） | `⌃⌥←` |
| 1文戻る | `⌃⌥↑` |
| 1文進む | `⌃⌥↓` |
| 停止 | `⌃⌥.` |
| クリップボードを読む | `⌃⌥C` |

矢印の4方向で覚えられます。**左右が速さ、上下が文の移動**です。
速度は1段ずつ動き、端では止まります（一周しません）。

**覚えるのは `⌃⌥P` と `⌃⌥C` の2つで足ります。** 残りはメニューの右側に出ています。

速度は **1.0〜1.5 の範囲だけ**にしてあります。それより遅くすると、時間を引き伸ばす処理の
都合で音が濁り、聞けたものではなくなるためです。試したい場合は `rateLadder` に手で足せます。

`⌃` は Control、`⌥` は Option です。

`⌥⌘→` / `⌥⌘←` を使っていないのは、Chrome・Safari・VS Code が「次のタブ／前のタブ」に
既定で割り当てているからです。奪うと全アプリでタブ切り替えが壊れます。

### 3つの入口

**① Claude Code のフック（自動）**

応答が終わるたび、その本文が nagara へ渡ります。**鳴りません。** メニューバーのアイコンに
未再生の件数が付くだけです。聴きたくなったら `⌃⌥P` を押します。

ターミナルの表示ではなく会話ログから本文を取るので、プロンプト記号も進捗表示も混ざりません。

**② CLI**

```bash
nagara "読ませたい文章"     # 積むだけ（鳴らない）
echo "..." | nagara         # 標準入力から
nagara --now "すぐ読んで"    # 積んですぐ鳴らす
nagara play | pause | toggle | stop | back | next
nagara clipboard            # クリップボードの中身を読む
nagara rate                 # 1.0 → 1.2 → 1.5 と回す
nagara rate 1.5             # 指定する
nagara status               # いまの状態
```

テキストを吐けるものなら何でも繋がります。Codex でも cron でも自作スクリプトでも。

**③ 選択したテキスト**

2通りあります。

**`⌘C` でコピー → `⌃⌥C`。** これが確実で、**どのアプリでも効きます**。

もうひとつが右クリック → **「nagara で読む」**（macOS のサービス）。ただし
**出てこないアプリがあります。** Electron 製のアプリ（Claude Code のデスクトップ版もそう）は
コンテキストメニューを自前で描いていて、macOS のサービスを載せません。
Safari・Mail・メモ・テキストエディットのような素の AppKit のテキスト欄なら出ます。

初回だけ、システム設定 > キーボード > キーボードショートカット > サービス で
有効化が要ることがあります。

どちらの経路も、**選択していないものは読みません。** メニューバーやボタンのラベルが
読み上げられることはありません。

### スラッシュコマンド

Claude Code のチャット欄から:

- `/speak` — 直前の応答を読む
- `/stop` — 止める

打っている間も喋り続けるので、**実用上は `⌃⌥.` のほうが速い**です。

## メニューバー

アイコンで状態が分かります。吹き出しを基本形にしているのは、
[nobetsu](https://github.com/pochang6/nobetsu) の波形アイコンと並んだときに見分けるためです。

| 見た目 | 状態 |
|---|---|
| 吹き出し（線） | 待機中。何も届いていない |
| 吹き出し（塗り）+ 数字 | 未再生あり。届いているが鳴っていない |
| スピーカー | 再生中 |
| 一時停止マーク | 一時停止中 |

```
未再生 3 件
─────────────
最新を再生 / 一時停止        ⌃⌥P
停止                        ⌃⌥.
1文戻る                     ⌃⌥↑
1文進む                     ⌃⌥↓
─────────────
クリップボードを読む          ⌃⌥C
─────────────
速度 ▸ 速く ⌃⌥→ / 遅く ⌃⌥← / 1.0 … 1.5
声   ▸ まい / コハク ▸ … / まお ▸ …
□ 自動再生
─────────────
履歴 ▸ 直近15件（クリックで再生）
─────────────
AivisSpeech ▸ 状態 / 起動・終了 / 使い終わったら…
─────────────
☑ ログイン時に起動
設定ファイルを開く / ログを開く
nagara を終了
```

**声の一覧はハードコードしていません。** 起動時に AivisSpeech へ問い合わせるので、
新しいモデルを入れれば何もしなくてもメニューに増えます。

**自動再生は既定 OFF** です。応答のたびに喋られると邪魔なので、
「届いてはいるが鳴っていない」が通常の状態になります。

## AivisSpeech の扱い

必要になった時点で `open -g -j` で裏起動し、モデルの読み込みを待ちます（十数秒）。

**一度起きたエンジンは置いておきます。** ただし **15分使われなければ静かに落とします**。
起動のたびに待たされるのも、一日中居座られるのも避けたいので、その折り合いです。
メニューから「起動したままにする」「nagara の終了時に閉じる」にも変えられます。

**自分で起こしたエンジンだけが対象**で、あなたが手で開いたものには触りません。
手で閉じた場合も追いかけません（次に必要になったときだけ、また起こします）。

> **既知の制約**: AivisSpeech は Electron 製で、起動時に自分でウィンドウを前面へ出します。
> nagara は見つけ次第 hide し続けますが、**一瞬ちらつくのは避けられません**。
> 完全に消すには GUI を持たない AivisSpeech-Engine 単体版に差し替える必要があります。

## 設定

`~/Library/Application Support/nagara/settings.json`

| 項目 | 既定 | 意味 |
|---|---|---|
| `speakerId` | `1431611904` | 話者のスタイル ID（まい / ノーマル） |
| `rate` | `1.0` | いまの再生速度。**そのまま次回の既定になります** |
| `rateLadder` | `[1.0 … 1.5]` | `⌃⌥→` `⌃⌥←` で1段ずつ動く段階 |
| `autoPlay` | `false` | 届いた端から鳴らすか |
| `port` | `17371` | 受け口。`127.0.0.1` にしか bind しません |
| `engineURL` | `http://127.0.0.1:10101` | VOICEVOX なら `:50021` |
| `engineIdleQuitMinutes` | `15` | 使われないエンジンを閉じるまでの分数（0 で閉じない） |
| `skipCodeBlocks` | `true` | コードブロックを読み飛ばす |
| `minimumLength` | `12` | これより短い応答は積まない |

ログは `~/Library/Logs/nagara.log` です。

---

## いま出来ていないこと

- 任意の位置へのシーク（戻せるのは1文ずつ）
- メディアキー・コントロールセンターからの操作（Now Playing 未対応）
- Codex のフック連携（CLI と右クリックでは使えます）
- アバター表示
